# Nexora AI Portfolio

A simple, dependency-free portfolio website for a web + AI service business.

## Run locally
Open `index.html` in a browser.

## Before publishing
1. Replace `YOUR NUMBER` and `YOUR EMAIL` in `index.html`.
2. Replace `YOUR_EMAIL@example.com` in `script.js`.
3. Review prices and demo claims.
4. Add your real portfolio links when you have client projects.

## Publish
This is plain HTML/CSS/JS, so it can be hosted on GitHub Pages, Netlify, or Vercel without a build step.
